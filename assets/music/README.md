# Background music

Music is a major part of The Way of Christ: inspiring, cinematic, emotional instrumentals that build
gradually and become powerful at the key moments. The pipeline shapes the volume for you: low under
the struggle, ducked under every word, swelling in the pauses and rising to its fullest at the end.

Organise tracks by feel. The folder or file name picks the track for each video (`music_moods` in
channel.yaml):

    assets/music/cinematic/   rising, hopeful, building tracks (piano + strings, swelling pads, gentle percussion
                              that grows): used for motivational, Bible story, Jesus and fact videos
    assets/music/prayer/      calm piano, ambient pads, soft strings: used for prayers and sleep videos

Look for: a slow, quiet start and a clear build (so the ending can soar), no lyrics, no sudden drops.
Search terms that work: "cinematic inspirational piano", "emotional orchestral build", "hopeful
ambient", "worship instrumental", "epic uplifting strings".

Only use music you are licensed to use on YouTube, for example:
- YouTube Studio's Audio Library (free, cleared for YouTube; filter by mood "Inspirational" or "Dramatic")
- a paid library licence (Epidemic Sound, Artlist, Musicbed) registered to the channel

Files in this folder are not committed to Git (see .gitignore), so add them on each machine, or
commit them deliberately if your licence allows.
