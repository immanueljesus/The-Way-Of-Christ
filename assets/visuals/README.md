# Your own artwork (optional)

Images or clips in this folder are used before stock footage whenever their file name shares
words with a scene's footage search. The scriptwriter writes searches like "shepherd sheep hillside",
"prison cell light" or "stormy sea boat", so name files the same way:

    joseph-prison-cell-light.jpg
    david/shepherd-sheep-hillside.png
    peter-fishing-boat-storm.mp4

Good sources: AI-generated cinematic scenes you made yourself (one consistent style per series),
public-domain paintings (Rembrandt, Caravaggio, Tissot, Doré on Wikimedia Commons), and footage you
licensed. Supported: jpg, jpeg, png, webp, mp4, mov. Subfolders are searched too.

Every Bible-story idea that names a Wikipedia article also gets that article's paintings
automatically, with credits added to the description.
